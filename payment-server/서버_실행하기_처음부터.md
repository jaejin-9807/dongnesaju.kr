# 서버 실행하기 (처음이신 분을 위한 A-Z 가이드)

## 먼저 알아야 할 것: 왜 파일을 더블클릭하면 안 되나요?

지금까지 겪으신 "양식 다운로드가 안 된다", "Failed to fetch 오류가 뜬다"의 원인을
찾았습니다. `index.html` 파일을 탐색기에서 더블클릭해서 열면 브라우저 주소창에

```
file:///C:/Users/djcoo/AppData/Roaming/...index.html
```

같은 주소가 뜹니다. 이 상태에서는 페이지 안의 "서버에 물어보는" 모든 기능(양식 다운로드,
운세 계산, 결제 등)이 전부 작동하지 않습니다. 이 사이트는 **반드시 컴퓨터 안에서 작은
서버 프로그램을 켜놓은 상태로, 그 서버 주소(`http://localhost:3000`)로 접속**해야만
정상 작동하는 구조입니다. 카페 매장이 문을 열어야 손님을 받을 수 있는 것과 같습니다 —
`index.html`은 매장 간판일 뿐이고, `npm start`가 매장 문을 여는 행위입니다.

## 0단계. Node.js 설치 (컴퓨터에 한 번만 하면 됨)

1. https://nodejs.org 접속
2. 초록색 큰 버튼(**LTS** 라고 적힌 버전)을 눌러 설치 파일 다운로드
3. 다운로드된 설치 파일을 실행 → "Next"를 계속 눌러 기본 설정으로 설치 완료
4. 설치가 끝나면 **모든 실행 중인 창을 닫고**, 새로 시작 메뉴에서 "명령 프롬프트"
   (또는 "PowerShell")를 실행

설치가 잘 됐는지 확인하려면, 명령 프롬프트에 아래를 입력하고 Enter:
```
node --version
```
`v20.x.x` 같은 버전 번호가 나오면 성공입니다.

## 0-1단계. LibreOffice 설치 (사주풀이 PDF를 만들기 위해 꼭 필요, 한 번만 하면 됨)

사주풀이 결과지(PDF)는 "LibreOffice"라는 무료 프로그램을 이용해 만들어집니다.
이게 설치되어 있지 않으면 "샘플 PDF 생성" 이나 "운세풀이 시작하기" 버튼을 눌러도
오류가 납니다.

1. https://www.libreoffice.org/download/download-libreoffice/ 접속
2. "Download" 버튼을 눌러 설치 파일(.msi) 다운로드
3. 다운로드된 파일 실행 → 기본 설정 그대로 "다음 → 다음 → 설치"
4. 설치가 끝나면 **현재 열려 있는 명령 프롬프트 창을 완전히 닫고 새로 열어야** PATH가
   반영됩니다 (설치 도중 열려 있던 창에서는 계속 인식이 안 될 수 있어요).

## 1단계. 프로젝트 폴더로 이동

받으신 `payment-server` 폴더가 실제로 어디 있는지 확인하세요. 예를 들어
바탕화면에 두셨다면 명령 프롬프트에 아래처럼 입력합니다 (본인 경로에 맞게 수정):

```
cd Desktop\payment-server
```

또는 폴더 경로를 정확히 모르시면, 탐색기에서 `payment-server` 폴더를 열고
주소창을 클릭해 전체 경로를 복사한 뒤, 명령 프롬프트에 `cd ` 를 입력하고
바로 뒤에 붙여넣기 하면 됩니다.

## 2단계. 필요한 부품 설치 (최초 1회만)

```
npm install
```

몇 십 초에서 1~2분 정도 걸립니다. "added XX packages" 같은 메시지가 뜨면 완료입니다.

## 3단계. 환경설정 파일(.env) 만들기

```
copy .env.example .env
```

그다음 `payment-server` 폴더 안의 `.env` 파일을 **메모장으로 열어서** 아래 두 줄을
본인이 토스 개발자센터에서 발급받은 값으로 바꿔주세요.

```
TOSS_CLIENT_KEY=test_ck_d46qopOB892l5MBZp7PE3ZmM75y0
TOSS_SECRET_KEY=(토스 개발자센터에서 "보기"를 눌러 확인한 시크릿키 전체를 여기에)
```

바꾼 뒤 저장하고 메모장을 닫으세요.

## 4단계. 서버 실행

```
npm start
```

아래와 같은 메시지가 뜨면 성공입니다:
```
동네사주카페 서버 실행 중: http://localhost:3000
```

만약 오류 메시지의 한글이 `????` 처럼 깨져서 나온다면, 대신 아래 명령으로 실행해 보세요.
(명령 프롬프트의 한글 표시 방식을 UTF-8로 바꿔서 실행하는 명령입니다)
```
npm run start:win
```

**이 검은 창(명령 프롬프트)을 닫지 마세요.** 이 창이 곧 "서버가 켜진 상태"입니다.
창을 닫으면 서버도 같이 꺼져서 사이트가 다시 안 열립니다. 사용하는 동안은 계속 켜두시고,
필요 없을 때는 이 창에서 `Ctrl+C`를 눌러 끄시면 됩니다.

## 5단계. 브라우저로 접속

주소창에 `file://...` 가 아니라 아래 주소를 **직접 입력**해서 들어가세요.

```
http://localhost:3000
```

이제 양식 다운로드, 주문서 업로드, 운세 계산, 결제까지 전부 정상 작동합니다.

## 자주 겪는 문제

- **"npm install"에서 오류가 난다**: Node.js가 제대로 설치됐는지 `node --version`으로
  다시 확인해 보세요. 안 되면 컴퓨터를 재시작한 뒤 다시 시도해 보세요.
- **"npm start" 후 바로 창이 꺼진다**: 오류 메시지를 그대로 복사해서 알려주시면
  원인을 찾아드릴 수 있습니다.
- **양식은 받아지는데 업로드가 안 된다**: `.env` 파일에 토스 키를 정확히 넣었는지,
  `TOSS_CLIENT_KEY=` 뒤에 공백이나 따옴표가 들어가지 않았는지 확인해 주세요.
- **결제창까지는 잘 뜨는데 승인이 안 된다**: 테스트 카드번호
  `4330-0000-0000-0005`, 유효기간/CVC/비밀번호는 아무 숫자나 입력해 보세요.

## 토스 "홈페이지 주소를 입력해주세요" 화면이 떴다면

그 화면은 "결제위젯" 방식을 심사받기 위한 신청서입니다. 지금 사용 중인 코드는
심사가 필요 없는 **"API 개별 연동 키"** 방식으로 이미 만들어져 있으니, 그 화면에서는
왼쪽 위 "이전"을 눌러 신청을 취소하고 나오시면 됩니다. API 개별 연동 키(화면에서
`test_ck_...`로 시작하던 키)만 있으면 별도 신청 없이 바로 테스트할 수 있습니다.

## 소셜 로그인(네이버/카카오/구글) 키 발급 절차

회원가입/로그인 화면의 "네이버로 로그인" / "카카오로 로그인" / "구글로 로그인" 버튼은
코드가 이미 완성되어 있으며, `.env` 파일에 각 사에서 발급받은 키만 넣으면 바로 동작합니다.
키가 비어 있는 동안은 버튼을 눌러도 "키 등록 전이라 준비 중입니다" 안내만 뜨고,
기존 이메일+비밀번호 로그인은 그대로 정상 작동합니다.

서버를 실행 중인 상태에서 진행해야 콜백 주소가 정확히 맞는지 확인하기 쉽습니다.
로컬 테스트는 `http://localhost:3000`, 실제 서비스 오픈 후에는 실제 도메인 주소로
아래 콜백 URL의 `localhost:3000` 부분만 바꿔서 등록하면 됩니다.

### 1) 네이버 로그인 키 발급

1. https://developers.naver.com/apps/#/register 접속 후 네이버 아이디로 로그인
2. "애플리케이션 등록" 클릭
3. 애플리케이션 이름: `동네사주카페` (자유롭게 입력)
4. 사용 API: **네이버 로그인** 체크
5. 제공 정보 선택: 이메일 주소, 이름 체크 (필수 동의로 설정 권장)
6. 로그인 오픈 API 서비스 환경: **PC웹** 체크
7. 서비스 URL: `http://localhost:3000` (실서비스는 실제 도메인)
8. Callback URL: `http://localhost:3000/api/auth/naver/callback`
9. 등록 완료 후 발급되는 **Client ID**, **Client Secret**을 복사
10. `.env` 파일의 `NAVER_CLIENT_ID=`, `NAVER_CLIENT_SECRET=` 뒤에 붙여넣기

### 2) 카카오 로그인 키 발급

1. https://developers.kakao.com/console/app 접속 후 카카오 계정으로 로그인
2. "애플리케이션 추가하기" 클릭, 앱 이름 `동네사주카페` 입력
3. 좌측 메뉴 "카카오 로그인" 클릭 → 활성화 설정 **ON**
4. Redirect URI 등록: `http://localhost:3000/api/auth/kakao/callback`
5. 좌측 메뉴 "동의항목"에서 이메일(선택 동의 또는 필수 동의), 닉네임 항목 활성화
   - 이메일 항목은 카카오 비즈니스 채널 연동 등 추가 심사가 필요할 수 있습니다.
     심사 전에는 이메일이 비어 올 수 있는데, 이 경우도 자동으로 임시 이메일을
     만들어 회원가입되도록 이미 처리되어 있어 서비스 이용에는 문제 없습니다.
6. 좌측 메뉴 "앱 키"에서 **REST API 키** 복사
7. `.env` 파일의 `KAKAO_CLIENT_ID=` 뒤에 REST API 키 붙여넣기
   (카카오는 시크릿 없이도 기본 동작합니다. "보안 > Client Secret"을 별도로
   켠 경우에만 `KAKAO_CLIENT_SECRET=`에도 값을 채워주세요.)

### 3) 구글 로그인 키 발급

1. https://console.cloud.google.com/ 접속 후 구글 계정으로 로그인
2. 상단에서 새 프로젝트 생성 (이름 예: 동네사주카페)
3. 좌측 메뉴 "API 및 서비스" → "OAuth 동의 화면"
   - User Type: **외부** 선택 → 앱 이름/이메일 등 입력 후 저장
4. 좌측 메뉴 "API 및 서비스" → "사용자 인증 정보" → "사용자 인증 정보 만들기"
   → **OAuth 클라이언트 ID** 선택
5. 애플리케이션 유형: **웹 애플리케이션**
6. 승인된 리디렉션 URI: `http://localhost:3000/api/auth/google/callback` 추가
7. 만들기 완료 후 발급되는 **클라이언트 ID**, **클라이언트 보안 비밀**을 복사
8. `.env` 파일의 `GOOGLE_CLIENT_ID=`, `GOOGLE_CLIENT_SECRET=` 뒤에 붙여넣기

### 4) 적용 확인

세 곳 모두(또는 일부만) `.env`에 키를 넣은 뒤 서버를 껐다 다시 켜면(`Ctrl+C` 후 재실행)
바로 반영됩니다. 로그인 페이지(`/login.html`)에서 해당 버튼을 눌렀을 때 각 사의
로그인 화면으로 이동하면 정상 연결된 것입니다. 로그인/동의 후에는 자동으로
마이페이지(`/my.html`)로 이동하며 회원가입도 함께 처리됩니다(첫 로그인 시 자동 가입).
