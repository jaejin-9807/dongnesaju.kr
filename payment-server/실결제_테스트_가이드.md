# 1원 실결제 테스트 가이드

## 지금 상황 정리

**"주문서 양식 다운로드가 안 된다"** 는 문제의 원인은 코드 버그가 아니라, 개발 환경(Cowork
세션)에서는 서버가 명령 하나가 끝나면 같이 종료되기 때문입니다. 실제로 서버를 띄운 상태에서
직접 테스트해보니 다운로드, 업로드, 계산, PDF 생성까지 전부 정상 작동했습니다. **본인 컴퓨터에서
`npm start`로 서버를 직접 실행해두면 이 문제는 사라집니다.** (아래 "서버 실행 방법" 참고)

**"1원 결제가 실제로 되는지"** 에 대해서는 중요한 사실이 있습니다.

> 토스페이먼츠 공식 문서(방금 확인)에 따르면, **`test_` 로 시작하는 테스트 키로는 실제 카드
> 정보를 입력해도 결제가 가상으로만 승인되고, 실제로는 절대 돈이 출금되지 않습니다.**

즉 지금 `.env.example`에 들어있는 토스 테스트 키(`test_gck_...`, `test_gsk_...`)로는
"연동이 잘 되는지"는 완벽하게 검증할 수 있지만, 진짜 1원이라도 실제로 빠져나가는 결제는
**원천적으로 불가능**합니다. 진짜 1원 결제를 하려면 `live_gck_...` / `live_gsk_...` 라이브 키가
있어야 합니다.

## 두 단계로 나눠서 진행합니다

### 1단계: 테스트키로 "연동이 제대로 되는지"부터 확인 (지금 바로 가능)

1. 본인 컴퓨터에서 서버 실행 (아래 방법 참고)
2. 홈페이지에서 "1원 테스트" 상품으로 주문서 작성 → 업로드 → 결제창까지 진입
3. 토스 결제창에서 아래 **테스트 카드 번호**로 결제 시도
   - 카드번호: `4330-0000-0000-0005` (토스 공식 테스트 카드, 유효기간/CVC는 아무 값이나 가능)
   - 승인이 뜨고 PDF가 생성되고 이메일이 오는지까지 전체 흐름을 확인
4. 여기까지 정상 작동하면, **연동 코드 자체는 완성된 것**이고 남은 건 라이브 키로 바꾸는 것뿐입니다.

### 2단계: 라이브 키 발급 후 진짜 1원 결제 (심사 필요, 시간이 걸림)

라이브 키는 토스페이먼츠가 "이 사업자가 실제로 결제를 받아도 되는 곳인지" 심사를 마쳐야
발급됩니다. 아래 순서로 진행하세요.

1. https://developers.tosspayments.com 접속 → 회원가입/로그인
2. 개발자센터 → "내 상점" → "상점 등록" 또는 "심사 신청"
3. 필요 서류 (개인/개인사업자/법인 중 선택):
   - 개인: 신분증, 통장 사본
   - 개인사업자: 사업자등록증, 통장 사본, 대표자 신분증
   - 법인: 법인등기부등본, 사업자등록증, 법인통장 사본 등
4. 심사는 보통 영업일 기준 며칠 정도 소요됩니다 (토스 측 심사 속도에 따라 다름)
5. 심사 통과 후 개발자센터 → "API 키" 메뉴에서 **라이브 클라이언트 키(`live_gck_...`)와
   라이브 시크릿 키(`live_gsk_...`)** 발급
6. `.env`의 `TOSS_CLIENT_KEY`, `TOSS_SECRET_KEY`를 라이브 키로 교체 → 서버 재시작
7. 이제 "1원 테스트" 상품으로 실제 본인 카드를 긁으면 **진짜 1원이 출금**됩니다.
   (환불하고 싶으면 토스 개발자센터의 "결제내역"에서 취소 가능합니다.)

라이브 전환 시 이 코드에서 바꿔야 할 곳은 `.env` 두 줄뿐입니다. 코드 구조는 이미
테스트/라이브 키를 그대로 갈아끼우기만 하면 되도록 만들어져 있습니다.

## 서버 실행 방법 (본인 컴퓨터에서)

Cowork는 매 작업이 끝나면 프로세스가 종료되는 구조라, 실제 서비스처럼 계속 켜두려면
본인 컴퓨터(또는 서버)에서 직접 실행해야 합니다.

```bash
# 1. Node.js가 설치되어 있어야 합니다 (https://nodejs.org 에서 설치, LTS 버전 권장)
cd payment-server
npm install
cp .env.example .env
# .env 파일을 열어 필요한 값 채우기 (최소한 토스 키는 예시값 그대로 둬도 테스트 가능)
npm start
```

`동네사주카페 서버 실행 중: http://localhost:3000` 메시지가 뜨면 성공입니다.
이제 브라우저에서 `http://localhost:3000` 을 열면 홈페이지가 뜨고, 창을 닫지 않는 한
서버가 계속 켜져 있습니다. (터미널 창을 닫으면 서버도 같이 꺼집니다 — 계속 띄워두려면
터미널을 열어둔 채로 두거나, `pm2` 같은 프로세스 매니저를 쓰면 백그라운드로 상시 실행됩니다.)

## 주문서 양식 사용 시 주의

지금 양식에 예시 행이 3개(정통사주/1원 테스트/2025월운) 들어있는데, 서버는 **가장 위(3행)에
있는 주문만** 처리합니다. 1원 테스트를 하려면:
- 3행(정통사주)과 5행(2025월운) 예시 줄을 지우고 **1원 테스트 행만 남기거나**
- 1원 테스트 행을 3행 위치로 옮기거나
- 아예 3행부터 본인이 원하는 정보로 새로 입력

## 지금 실제로 검증된 것 (이 세션에서 서버를 띄워 직접 확인함)

- 양식 다운로드 API → 200 OK, 정상 xlsx 파일 (엑셀에서 바로 열림)
- 엑셀 업로드 → 파싱 → 실제 사주 계산 엔진 실행 → 정상 결과 반환
- 결제 금액 위변조 방지 로직 정상 작동 (다른 금액으로 승인 시도 시 차단)
- PDF 결과지 생성 (7페이지, 한글 정상 렌더링) 및 다운로드
- 이메일 발송 로직 (메일 계정 없을 때 결제를 실패시키지 않고 안전하게 에러 기록하는 것까지 확인)

즉 **코드 자체에는 문제가 없고**, 지금 필요한 건 (1) 본인 컴퓨터에서 서버를 계속 띄워두는 것과
(2) 진짜 1원이 나가는 결제를 원하시면 라이브 키 발급(사업자 심사)입니다.

## [업데이트] API 개별 연동 키로 전환 완료 + 실제 테스트 진행 방법

토스 개발자센터 화면에서 확인하신 키는 **"API 개별 연동 키"** 입니다. 기존 코드는
"결제위젯 연동 키" 전용 SDK(`widgets()`)로 만들어져 있어서, API 개별 연동 키와 호환되도록
표준 결제창 방식(`payment()`)으로 `public/payment-toss.html`을 다시 만들었습니다.

### 이 세션에서 확인한 것 (샌드박스 환경의 한계 포함)

- 서버를 띄우고 `/api/toss/client-key`를 호출해 **제공하신 클라이언트키가 정확히 반영되어
  응답으로 나오는 것**을 확인했습니다.
- "1원 테스트" 주문을 실제로 업로드해서 **금액이 정확히 1원으로 주문에 저장되는 것**을 확인했습니다.
- `payment-toss.html` 페이지가 정상적으로 로딩되는 것을 확인했습니다.
- **다만 이 개발 환경(Cowork 샌드박스)은 보안상 외부 인터넷 접속이 프록시로 제한되어 있어서,
  실제로 `api.tosspayments.com` 서버와 통신하는 최종 결제 승인 단계까지는 이 환경 안에서
  검증할 수 없었습니다.** (구글 등 다른 외부 사이트도 마찬가지로 막혀 있습니다.) 이는 코드
  문제가 아니라 실행 환경의 제약이며, 본인 컴퓨터에서 실행하면 정상적으로 외부 인터넷에
  접속되어 문제없이 동작합니다.

### 본인 컴퓨터에서 진짜로 1원 테스트 결제를 해보는 방법

1. `.env.example`을 복사해 `.env` 생성
2. `.env`를 열어 아래처럼 본인이 발급받은 키로 교체
   ```
   TOSS_CLIENT_KEY=test_ck_d46qopOB892l5MBZp7PE3ZmM75y0
   TOSS_SECRET_KEY=(개발자센터에서 "보기"를 눌러 확인한 시크릿키 전체)
   ```
   (시크릿키는 화면에서 `test_sk_****...`로 마스킹되어 있으니, "보기" 버튼을 눌러
   전체 값을 확인한 뒤 붙여넣어 주세요.)
3. `npm install` → `npm start` 로 서버 실행
4. 브라우저에서 `http://localhost:3000` 접속
5. 주문서 양식 다운로드 → **1원 테스트** 행만 남기고(또는 맨 위로 옮기고) 작성 → 업로드
6. "운세를 만들고 있습니다" → "받아보시겠어요?" → 확인 → 결제수단에서 토스페이먼츠 선택
7. 결제창에서 아래 테스트 카드로 결제
   - 카드번호: `4330-0000-0000-0005`
   - 유효기간/CVC/비밀번호 앞 2자리: 아무 값이나 입력 가능
8. **주의**: 지금 갖고 계신 키는 `test_` 로 시작하는 테스트 키이므로, 결제창에서 승인이
   떨어지고 PDF/이메일까지 정상적으로 오는 것은 확인되지만, **실제 카드에서 1원이 빠져나가지는
   않습니다.** (토스 공식 문서에 명시된 테스트 환경의 정책입니다.) 진짜 출금까지 확인하려면
   앞서 안내드린 라이브 키 발급(사업자 심사)이 필요합니다.
